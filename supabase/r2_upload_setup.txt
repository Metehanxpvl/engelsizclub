Cloudflare R2 — ilan fotoğrafları (Supabase Storage YOK)
========================================================

Akış:
  Flutter → Supabase Edge Function `r2-upload` → R2 bucket → public URL
  URL `ilanlar.photos` JSON'una yazılır (sadece link; dosya Supabase'de değil).

Bucket: engelsizclub-ilanlar
Public URL örneği: https://pub-XXXX.r2.dev

--------------------------------------------------------
A) Cloudflare — Public Access (FOTOĞRAFLARIN GÖRÜNMESİ İÇİN ŞART)
--------------------------------------------------------
1. https://dash.cloudflare.com → R2 Object Storage
2. Bucket: engelsizclub-ilanlar
3. Settings → Public access → Allow Access (r2.dev subdomain)
4. Açılan URL'yi kopyala: https://pub-........r2.dev
5. (İsteğe bağlı) CORS — Settings → CORS policy:

[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag", "Content-Length", "Content-Type"],
    "MaxAgeSeconds": 3600
  }
]

--------------------------------------------------------
B) API Token (API Access) — yükleme için
--------------------------------------------------------
R2 → Manage R2 API Tokens → Create API token
  Permissions: Object Read & Write (bu bucket)
  Not the values: Access Key ID + Secret Access Key
  Account ID: sağ panelde

--------------------------------------------------------
C) Supabase secrets + deploy
--------------------------------------------------------
supabase secrets set ^
  R2_ACCESS_KEY_ID=... ^
  R2_SECRET_ACCESS_KEY=... ^
  R2_BUCKET_NAME=engelsizclub-ilanlar ^
  R2_ACCOUNT_ID=... ^
  R2_PUBLIC_URL=https://pub-XXXX.r2.dev

supabase functions deploy r2-upload

Lokal referans: proje kökü `.env` (git'e girmez). Uygulama secret okumaz.

--------------------------------------------------------
D) Test
--------------------------------------------------------
Tarayıcıda şunu aç (örnek key ile yükledikten sonra):
  https://pub-XXXX.r2.dev/ilanlar/<userId>/<dosya>.jpg
Açılmıyorsa Public Access kapalıdır — A adımına dön.
